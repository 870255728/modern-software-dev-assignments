# Week 5 候选任务

## 已完成任务

### 任务 3：完整 Notes CRUD 与乐观 UI（中等）

- 新增 `PUT /notes/{id}` 和 `DELETE /notes/{id}`。
- 使用 Pydantic 校验标题和内容长度。
- 前端编辑、删除时先更新界面；请求失败后恢复原状态并显示错误。
- 测试覆盖成功、输入无效和资源不存在。

### 任务 4：Action Items 筛选与批量完成（中等）

- `GET /action-items?completed=true|false` 支持完成状态筛选。
- `POST /action-items/bulk-complete` 在一个事务中完成多个项目。
- 任意 ID 不存在时整体失败，禁止部分更新。
- 前端支持 All、Open、Completed 筛选、多选和批量完成。
- 测试覆盖筛选、批量行为和事务回滚。

## 其他候选任务

- **任务 1——迁移到 Vite + React（复杂）**：重建前端、接入现有 API，并增加组件测试。
- **任务 2——Notes 搜索、分页和排序（中等）**：实现组合查询、结果计数和翻页 UI。
- **任务 5——Tags 多对多功能（复杂）**：增加 Tag 模型、关联接口、标签筛选与测试。
- **任务 6——增强内容提取（中等）**：从 Note 中提取 `#标签` 和 Markdown 待办项。
- **任务 7——统一错误响应（简单至中等）**：增加全局异常处理和一致的 JSON 响应结构。
- **任务 8——集合分页（简单）**：为 Notes 和 Action Items 增加页码与每页数量。
- **任务 9——查询性能与索引（简单至中等）**：增加 SQLite 索引并检查查询计划。
- **任务 10——提高测试覆盖率（简单）**：补充错误、事务和前端交互测试。
- **任务 11——部署到 Vercel（中等至复杂）**：配置前端构建、API 部署、CORS 和回滚说明。

## 选题理由

任务 3 和任务 4 的后端路由相对独立，适合并行实现；但它们都会修改 `schemas.py` 和前端文件，因此能够真实体现 worktree 隔离、合并冲突、人工审查和完整回归测试的价值。
